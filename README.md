## О проекте

Этот репозиторий посвящён разработке Telegram-бота для решения прикладной бизнес-задачи в рамках курса [«Vibe Coding: AI-боты для бизнеса»](https://github.com/itmo-ict-faculty/vibe-coding-for-business).

Проект развивается последовательно: сначала работающий бот, затем интеграция с данными и, наконец, развёртывание для реальных пользователей. Исходный код, конфигурационные примеры и отчёты по лабораторным работам будут размещаться здесь по мере выполнения заданий.

## Запуск

Инструкции по установке зависимостей, настройке окружения и запуску бота появятся после реализации первой лабораторной работы. Основной стек — **Python** и **Telegram Bot API**.

Токены доступа и другие секреты не публикуются в репозитории. Для настройки будут использоваться переменные окружения и файлы-примеры без настоящих ключей.
