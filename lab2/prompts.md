# Lab 2: промпт и итерации

Исходное задание: [codex_lab2_lab3_FINAL_fast.md](../codex_lab2_lab3_FINAL_fast.md).

Пользователь поручил прочитать общий промпт и реализовать Lab 2/3 в существующем проекте: использовать локальные ключи без вывода значений, работать последовательно, настроить Docker LiteLLM/PostgreSQL, проверить ngrok/webhook и при ошибке вернуть polling, сразу исправить три замечания, не менять Lab 1/README, не делать commit/push, запускать настоящие тесты и выдать команды запуска.

Фактические итерации:

1. Изучены проект, тесты, отчёт Lab 1 и существующая Windows `.venv`. Отдельно проверены CUDA/PyTorch и 70 тестов с реальной E5.
2. Добавлены адаптеры OpenAlex, Crossref, DataCite и World Bank D&R, общий HTTP-кеш, фильтры и строгий DOI. Снимки вариантов источников добавлены без изменения исходной схемы Lab 1.
3. Подключён установленный Argos RU↔EN. Исправлена ошибка чтения/обновления Stanza `resources.json` без повторного скачивания моделей.
4. Добавлены LiteLLM management client, персональные ключи, `/limits`, ограниченный Responses client и защита от платных повторов. Проверены живые API, Proxy и превышение бюджета.
5. После тестов сохранены реальные ограничения: OpenAI вернул 401; успешная генерация и платный spend не заявляются проверенными.
6. После предоставления нового ключа подтверждены доступные ID моделей, настоящий ответ GPT-6 Luna через персональный ключ LiteLLM и запись стоимости $0.0000038. Ошибка 401 устранена; остаток пользователя уменьшился до $0.4999962.
7. При завершении владелец подтвердил работу поиска, ИИ и лимитов в Telegram. Функциональность заморожена; выполнены заключительные проверки и подготовлены документы для GitHub без commit/push.

Секреты, ответы с ключами и содержимое `.env` в этот журнал не включаются. Общая разработка выполнена без коммитов.
